Four games · no background needed

How do chatbots and AI agents really work?

Play them in order. In each learning game you do the AI's job yourself. Each arena then tests you against the clock, and your class can compete on a live scoreboard.

  1. 1 Learn · 25–30 min
    Be the LLM
    Guess the next word, train a tiny model, and see how a chatbot answers questions, and why it can sound sure and still be wrong.
  2. 2 Challenge · about 20 min · scoreboard
    LLM Arena
    Be the model against the clock: count, write, roll the temperature dice and answer chats exactly as the model would.
  3. 3 Learn · 25–30 min
    Be the Agent
    The desk (context window), reading files, tools, the agent loop, hidden instructions, and who's in charge.
  4. 4 Challenge · about 20 min · scoreboard
    Agent Arena
    Run the agent: pack the desk, search, pick tools, write table commands, catch planted orders and deliver a real Excel file.

Your progress is saved in this browser only. A tick appears when you finish a game on this device.

Made for teaching. Everything runs in your browser; the arenas send only a nickname, optional team, class code and scores to the class scoreboard.
